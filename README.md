# Larkspur Industries website

The company pages are generated from the HTML templates in `src/templates/`. Product documentation is generated from Markdown and MDX with Astro Starlight and published under `/docs/`.

## Requirements

- Node.js 24
- npm

## Development

```bash
npm ci
npm run dev
```

The development server serves the documentation at `http://localhost:4321/docs/` with live reload.

## Production build

```bash
npm run build
```

The build creates one deployable `dist/` directory containing the company site, product assets, documentation, Pagefind search index, sitemap, and legacy documentation redirects.

Run the same build plus output and local-link validation with:

```bash
npm test
```

To build and serve the complete production site locally:

```bash
./scripts/preview.sh
```

The default address is `http://127.0.0.1:4173`. Pass a different port as the first argument, for example `./scripts/preview.sh 8080`.

## Documentation structure

Documentation pages live in `src/content/docs/`. Add a Markdown or MDX file there, then register it in the sidebar in `astro.config.mjs` when it should appear in global navigation.

Static product files such as images, PDFs, and models remain in `docs/`. They are copied into the production artifact after Starlight builds.

Shared documentation branding is in `src/styles/docs.css`. SEO metadata and breadcrumb structured data are generated by Starlight and `src/components/DocsHead.astro`.
